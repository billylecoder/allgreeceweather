# AllGreeceWeather — απλό, self-hosted Hugo blog

Το AllGreeceWeather είναι ένα μικρό, στατικό blog για μετεωρολογικές αναλύσεις και προγνώσεις.

Δεν υπάρχει βάση δεδομένων, PHP, Node backend, δημόσιο admin panel ή εφαρμογή που πρέπει να τρέχει συνεχώς στον server.

## Τι επεξεργάζεσαι

Δημιούργησε άρθρα στον φάκελο:

```text
content/posts/
```

και βάλε τις εικόνες στον:

```text
static/images/
```

Ένα άρθρο έχει αυτή τη μορφή:

```markdown
---
title: "Νέο μετεωρολογικό άρθρο"
date: 2026-09-03T21:00:00+03:00
description: "Μια σύντομη περιγραφή που εμφανίζεται στην αρχική σελίδα."
image: "/images/my-photo.jpg"
draft: false
---

Το κείμενο του άρθρου γράφεται εδώ.

## Τίτλος ενότητας

Περισσότερο κείμενο.
```

Για νέο αρχείο μπορείς να χρησιμοποιήσεις:

```bash
hugo new content content/posts/to-arthro-mou.md
```

Όσο έχει `draft: true`, το άρθρο δεν εμφανίζεται στην κανονική έκδοση του site. Για δημοσίευση, βάλε `draft: false`.

## Τοπική προεπισκόπηση

Εγκατάστησε το Hugo και μετά, μέσα στον φάκελο του project, εκτέλεσε:

```bash
hugo server -D
```

Άνοιξε:

```text
http://localhost:1313
```

Η προεπισκόπηση λειτουργεί μόνο στον υπολογιστή σου και δεν δημοσιεύει τίποτα στο διαδίκτυο.

## Production build

Για να δημιουργηθεί η έτοιμη στατική ιστοσελίδα:

```bash
hugo --gc --minify
```

Τα τελικά αρχεία βρίσκονται στον φάκελο `public/`.

## Ρυθμίσεις site

Άνοιξε το `hugo.toml` και άλλαξε το:

```toml
baseURL = 'https://example.com/'
```

στο πραγματικό domain σου.

## Ασφάλεια

Το site είναι στατικό. Δεν δέχεται φόρμες, σχόλια, uploads χρηστών ή συνδέσεις σε βάση δεδομένων.

Η ρύθμιση του Hugo επιτρέπει μόνο Markdown, απενεργοποιεί unsafe HTML, inline shortcodes, εκτέλεση εντολών και απομακρυσμένα HTTP URLs κατά το build.

Αν φιλοξενείται σε δικό σου server, κράτησε ενημερωμένα το λειτουργικό σύστημα, το Nginx, το Hugo και το SSH. Χρησιμοποίησε SSH keys και ξεχωριστό non-root χρήστη για deployments.
